ACTÚA COMO:
Arquitecto de software senior, desarrollador full-stack senior, especialista en Laravel, MySQL, Vue 3, TypeScript, POS, facturación, facturación electrónica, inventario avanzado, sistemas SaaS multiempresa, PWA, impresión térmica ESC/POS, seguridad, auditoría, testing y arquitectura modular mantenible.

OBJETIVO GENERAL:
Desarrollar un sistema profesional tipo POS Touch + Facturación + Caja + Clientes + Productos + Servicios + Inventario + Reportes + Facturación Electrónica, adaptable a diferentes tipos de negocios mediante módulos activables/desactivables.

El sistema debe servir para:

- Restaurantes.
- Cafeterías.
- Food trucks.
- Colmados.
- Minimarkets.
- Supermercados.
- Bodegas.
- Almacenes.
- Distribuidoras.
- Tiendas.
- Ferreterías.
- Barberías.
- Salones.
- Talleres mecánicos.
- Repuestos.
- Servicios profesionales.
- Cualquier negocio que venda productos o servicios y necesite facturar.

REGLA CENTRAL:
El sistema no debe construirse como un POS rígido solo para restaurantes. Debe construirse como una plataforma modular de facturación y ventas adaptable por tipo de negocio.

   - O permitir con advertencia.
   Esto debe ser configurable.

2. Si está próximo a vencer:
   - Mostrar alerta.
   - Permitir venta.
   - Registrar auditoría.
   - Opcional sugerir descuento.

3. Si requiere lote:
   - Descontar por FEFO/FIFO.
   - O permitir selección manual.

4. Si requiere vencimiento y no tiene lote válido:
   - No permitir venta.
